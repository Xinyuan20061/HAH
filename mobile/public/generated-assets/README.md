# 首页英雄区背景图

**当前已安装：`home-hero.jpg`**（1024×1536，270 KB）

首页上半屏（90vh）用它作为封面，底部自动叠加一层渐变过渡到系统底色 `#f5f4ef`。

## 更换图片

直接替换 `home-hero.jpg` 即可，**不需要改任何代码**。

- 路径由 `miniprogram/config/index.js` 的 `HOME_HERO_IMAGE` 控制，想换文件名改那一行。
- 建议竖版，宽高比接近 **750:1112 ≈ 0.675**（当前图 0.667，`aspectFill` 只裁掉 1.2%，几乎全幅可见）。比例差得越多，被裁掉的部分越多。
- 建议宽度 ≥ 1024px、体积控制在 **300 KB 以内**（主包上限 2 MB，当前图占 13%）。
- 图片底部**不需要**自己画渐变，代码里已经叠了。

## 构图注意

英雄区里固定叠了这些元素（百分比按整屏高度算），选图时避开对应区域：

| 位置 | 元素 |
|---|---|
| 左上 | 日期文字（白字 + 投影） |
| 右上 | 圆形「记录」按钮 |
| 12%–30% | 大号坚持天数 +「坚持天数」白胶囊 |
| 53%–83% | 渐变过渡带（底部 8% 是纯 `#f5f4ef`，保证衔接处没有分割线） |
| 68%–76% | 7 日打卡条（深色磨砂底 + 薄荷绿圆点，压在渐变上） |
| 79%–88% | 「开始」按钮（骑在图片与底色的交界线上） |

主体（人物 / 静物）最好落在**画面中部**（约 30%–65% 高度），这样既不会被顶部文字压住，也不会被底部的打卡条和按钮遮挡。

## 回退

删除 `home-hero.jpg`，首页会自动回退到内置深绿渐变（`binderror` 已处理），不会报错也不会留白。
