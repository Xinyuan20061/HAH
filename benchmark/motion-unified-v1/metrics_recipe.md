# 指标口径手册（motion-unified-v1）

> 状态：**口径冻结草案，待实现确认**。所有指标在统一结果契约（规格 4.4）落地后按本手册
> 计算；脚本骨架随 P0-B/P0-C 实现。历史 `motion-v1` 的 41.67% 等数字不得写入本报告作为新方案结果。

## 1. 通用口径

- 全样本 = 冻结 test 集全部样本（S1~S5），含拒识、失败、非锻炼片；**拒识与失败一律计错**。
- 已接受样本 = 输出了 `recognized` 且 label 非空的样本。
- 覆盖率 coverage = 已接受样本数 / 全样本数。
- 一切报告必须同时给：分子、分母、样本量、清单 SHA-256、pipeline_version、模型版本。
- 95% 置信区间：
  - 比例类指标（准确率、召回、拒识率、Top-k、误报率）用 **Wilson score interval**（小样本不滥用正态近似）；
  - 均值类指标（次数 MAE、角度误差、时延 P50/P95）报告样本量与四分位距，必要时 bootstrap 2000 次。

## 2. 六类识别（S1，外加 S5 压力片的拒识考核）

| 指标 | 定义 | 禁止替代口径 |
| --- | --- | --- |
| 全样本准确率 | 全样本中 `recognized` 且 label 与真值一致的比例（拒识/失败/错分均错） | 只报已接受样本准确率 |
| 覆盖率 | 已接受 / 全样本 | — |
| Macro-F1 | 六类逐类 F1 算术平均（对 tp+fn=0 的类不参与，须注明） | 只报 Micro |
| 逐类召回 | 每类真值中被正确 recognized 的比例 | — |
| 拒识矩阵 | 2×2：{真值是应评价好片, 真值是应拒识片(S5/非锻炼)} × {系统 recognized, 系统 abstained/uncertain} | 只报总拒识率 |
| 95% CI | 全样本准确率 Wilson 区间 | 点估计无区间 |

拒识矩阵必须能区分：
- **正确拒识**（S5 质量片/非锻炼片被 abstain）——这是能力；
- **错拒**（S1 好片被无端 abstain）——这是损失。
防止"靠大量拒识把全样本准确率做高"。

## 4. DeepSeek 增益（四臂消融，见 ablation_matrix.json）

在**同一冻结集**上跑 A/B/C/D 四臂，报告：

- 净增益：`acc(D) − max(acc(B), acc(C))`，附 95% CI；
- 额外误判：D 相对 B 新增的错分/误接受逐条列表；
- 拒识变化：D 相对 B 的 abstain 率变化，并拆成正确拒识增量 vs 错拒增量；
- 延迟：每臂 P50/P95（ms）；
- 成本：每任务估算成本（元），含 DeepSeek 图像 token 与文本 token；与 `provider_invocations` 账本对账。

判定增益是否"真实"的门槛草案（待 dev 集调参后冻结）：净增益 CI 下限 > 0，且错拒增量不超过约定阈值，
且每任务成本在预算内。**不得把"点评更像人说话"当作增益证据。**

## 5. 关键帧与点评（人工标注 + 双人盲评）

| 指标 | 定义 | 容差/口径 |
| --- | --- | --- |
| 关键事件定位误差 | 模型输出的事件时间戳 vs 人工标注事件时间戳，按事件类型配对 | 默认容差 **±0.5 s**（可按动作周期在 dev 集标定后冻结；待实现确认）；窗口内配对成功才算命中，报告事件级 F1 与时间 MAE |
| 引用正确率 | 点评文本/关键帧中引用的 `frame_id` 是否真实存在于本次结果、且时间递增 | 服务端 Pydantic 已校验存在性；人工抽审"引用是否真的支撑该句观察" |
| 幻觉率 | 点评中出现：不存在的 frame_id、编造的角度/次数数值、无证据的阶段判断、医疗结论 | 双人盲评逐条打勾；幻觉率 = 幻觉句 / 总句 |
| 可执行建议评分 | 双人盲评对每条建议打：具体性、安全边界、可执行性（1–5） | 模板见 human_review_template.csv；分歧由第三人复核 |

铁律：模型输出**不得改变数值事实**（次数、角度、时间）；数值只由确定性代码写入。
人工盲评发现模型自报数值与测量值不一致时，记为"事实污染"事故，不计入普通幻觉。

## 6. 数值评分器（六类）

| 指标 | 定义 |
| --- | --- |
| 次数误差 | 评价器输出 reps vs 人工 reps：MAE、完全正确率、±1 正确率（只在 should_evaluate=true 样本） |
| 角度误差 | 关键关节角（如深蹲膝角）vs 人工/参考标注：MAE（度） |
| 评分一致性 | 同一素材重复跑 N 次的 quality_score 波动（标准差）；正面 vs 侧面机位的评分差异边界 |
| 无评价器动作 | 六类之外的动作，结果必须 `score.available=false` 且 `reason_code=NO_VALIDATED_SCORER`；人工抽审不得出现"给了分" |

## 7. 报告（report.md）必备章节（骨架）

1. 冻结信息：manifest SHA-256、样本量、受试者数、机位/光照 strata 分布、pipeline/model 版本、标注者、冻结日期。
2. 四臂对照表（覆盖率 / 全样本准确率 / Macro-F1 / 拒识率 / P50/P95 / 每任务成本）。
3. 六类逐类召回 + 拒识矩阵。
4. 400 目标子集 Top-1/Top-5、类外误报、分机位。
5. 关键事件 F1/时间 MAE、引用正确率、幻觉率、双人盲评一致性。
6. 六类评分器次数/角度误差与机位边界；无评价器动作 `score.available=false` 抽审记录。
7. 成本与失败案例摘要（对接 cost_tracking_template.csv）。
8. "不得据此宣称"声明：历史 41.67% 仅为历史基线；本报告不构成上线许可；候选分值不是准确率。
