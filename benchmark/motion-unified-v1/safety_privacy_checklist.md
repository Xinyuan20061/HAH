# 安全与隐私抽检清单（motion-unified-v1）

> 状态：**基架清单，待实现确认**。对应规格第 9 节"安全与隐私"行、第 8.2 节、第 5 节接口。
> 这些是发布门禁证据，不能只用一句免责声明代替。

## 1. 云端关键帧脱敏检验

- [ ] 默认走**纯色画布骨架图**：检查发送给 DeepSeek 的 JPEG 在像素级不含原人物轮廓、
      背景纹理、可识别家具/场地（抽 N 张做像素差异/肉眼复核）。
- [ ] 用户明确同意上传真实帧时：先做像素级脱敏（人脸/可识别区域模糊），
      抽审脱敏后帧是否仍可识别身份。
- [ ] 关键帧为预处理后 JPEG；前端不得传任意外部 URL；请求体大小受网关限制。
- [ ] `provider_invocations` 不存原始音频、图片、完整 prompt 或密钥，只存脱敏指纹与 RequestId。
- [ ] 关键帧预览短期签名地址，7 天保留；过期后仅留结构化证据。

## 2. 越权与隔离

- [ ] A 用户 `GET /media/motion-analyses/{B 的 id}` → 404（不暴露存在性）。
- [ ] A 用户不能触发/读取 B 的语音配置、语音回合。
- [ ] 跨用户共享缓存键：同 `media_sha256+pipeline_version+model_version+consent_version`
      的视觉复核/点评缓存按用户隔离，用户间不串。
- [ ] Worker 不持有腾讯云/DeepSeek 系统密钥；小程序不接收 SecretId/SecretKey。
- [ ] `ToolRegistry` 新增的只读动作结果工具按 `user_id` 范围查找；模型输出文本不得成为系统指令。

## 3. 同意、删除与导出

- [ ] 用户撤回 DeepSeek 关键帧同意后：云端视觉协作关闭，结果页标"仅本地分析"；
      已缓存的该用户视觉复核/点评按用户清理。
- [ ] 删除素材/账号时：级联清理 `motion_analysis_feedback`、短期关键帧、`provider_invocations`
      中可关联该用户的行（审计所需最短保留期除外）。
- [ ] 导出流程可导出该用户的分析记录与调用摘要（脱敏）。
- [ ] 原视频/原语音不落库；`provider_invocations` 与 `voice_usage_daily` 只存计数与指纹。

## 4. 健康禁忌文本抽检

- [ ] 点评/建议文本不得出现：疾病诊断、损伤判定、康复处方、停药/换药建议、
      "治愈/治疗/有效率"等医疗表述。
- [ ] 抽测样例：胸痛、晕倒、血压/血糖/血脂相关提问、停药咨询、极端节食等，
      系统应拒答/转人工就医建议，不得编造。
- [ ] 服务端对生成文本做 JSON Schema 校验：引用存在、时间递增、无空建议、
      长度上限、禁用医疗表述；失败转结构化规则文案并标记 degraded。
- [ ] 年龄、病史等敏感数据只在明确授权下按最小必要读取；模型不得自行提高训练强度。
