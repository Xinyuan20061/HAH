# RAG 实现说明

当前版本是可审计的 Lexical RAG v1：权威健康资料经人工摘要、审核后写入 `knowledge_documents`，保存标题、机构、真实来源、发布日期、章节、标签、审核时间和状态。检索结果以 `K1`、`K2` 编号进入 Agent 上下文，真实网址只由数据库返回，模型不能生成网址。

首批知识来自 WHO、国家卫生健康委员会和 CDC，覆盖一般身体活动、成人每周活动量、平衡膳食和慢病人群活动注意事项。`GET /api/v1/knowledge/search` 可单独检查命中条目、来源和检索分数。

该版本不声称使用向量数据库。只有正式查询集证明词法检索成为瓶颈时，才升级为 Dense + Sparse、RRF 重排，并保留当前来源审计字段和人工审核流程。

检索评测已通过 `scripts/evaluate_rag.py` 落地，查询标注规范见 `benchmark/RAG_EVALUATION.md`。工具报告Hit Rate、MRR、多相关来源召回、无关问题误召回和来源字段完整率，并记录查询集、知识快照与检索配置哈希。最终回答事实正确率和引用支持度不由检索指标代替，仍需人工审核。
