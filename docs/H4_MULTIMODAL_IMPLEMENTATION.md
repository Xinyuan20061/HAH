# HealthMate H4 多模态升级：严格审核与落地说明

## 结论

本轮采用“证据先于结论、确定性约束先于模型承诺、真实评测先于宣传数字”的原则。原提案中的逐项识餐证据、云端视觉模型适配、动作关键帧可视化和固定测试集协议值得进入主线；重复保存 Base64 图片、让模型直接触发写操作、在没有冻结测试集时给出准确率数字，不进入实现。

## 已落地架构

### 1. 逐食材识餐证据链

- 视觉模型必须输出 `items`，每项包含名称、份量依据、重量、热量与区间、营养素、置信度、可见证据和 `in_image`。
- Worker 与后端使用同构 Pydantic 模型双重校验，限制最多 12 项、有限数值、字段长度与取值范围。
- 整份热量由逐项热量确定；热量区间由逐项区间确定；重量和营养素同样由逐项汇总，避免“总数和明细各说各话”。
- 老版本结果会转换为一个明确标记为“旧版整体估算”的兼容项，不伪装成已完成逐项识别。
- 用户校正后，后端再次从明细计算总计；原始结果与校正结果分别保留，可用于后续误差分析。
- `diet_records.items_json` 持久化用户最终确认的逐项证据。本轮只新增迁移 `0016_food_item_evidence`。

### 2. 显式视觉模型提供方

- 新增 `VLM_PROVIDER=local|deepseek`，DeepSeek 使用独立的模型、Base URL 和 Key 配置。
- 兼容原项目把 DeepSeek Key 放在 `LOCAL_VLM_API_KEY` 的部署方式，便于平滑迁移；新部署应改用 `DEEPSEEK_API_KEY`。
- DeepSeek 路径固定使用 JSON 输出和关闭思考输出；请求失败只在“确实配置了另一套本地端点且错误可重试”时降级，不会把同一个云端地址伪装成本地回退。
- Worker 能力探测、doctor 冒烟检查和心跳元数据统一读取同一 provider 配置。

### 3. 动作事件视觉证据

- 从 MediaPipe 分析得到的真实事件秒数回到原视频截帧，最多生成 4 张关键证据图。
- 生成过程在本机完成：模糊肩部以上的人脸估计区域、叠加匿名骨骼与重点关节、写入事件和时间。
- 每图压缩到 80KB 以内；后端验证 Base64、JPEG 头尾、SHA-256、图片数量和整个结果 1MB 上限。
- 图片仅在 AI Job 结果中保留最多7天；`motion_events` 只保存结构化证据，避免数据库重复存图。小程序收到 Data URI 直接展示；无图或过期后继续使用原有骨骼画布降级。
- 关键帧是单机位二维训练证据，不是医学影像，也不用于诊断损伤。

### 4. 评测而不是演示数字

- 新增固定识餐测试集评测器和 JSONL 示例格式。
- 指标覆盖：任务完成率、全样本/成功样本菜名准确率、逐项食材 Precision/Recall/F1、热量 MAE/MAPE、热量区间覆盖率、明细汇总一致率、置信度 Brier 分数和光照/容器/遮挡分层。
- 失败样本计入全样本准确率和食材漏检，防止通过拒绝困难样本获得虚高结果。
- 输出记录标注文件与预测文件的 SHA-256，便于答辩现场证明结果可复现。
- 示例文件只能验证管线，不能作为比赛准确率。

## 对原提案的关键修正

1. 不新增关键帧图片表。Base64 再复制到独立 MySQL 表会增加体积、迁移和清理成本；当前受限预览直接跟随 AI Job 证据，事件表不重复保存。
2. 不让 LLM 静默创建任务或写健康数据。现有 `read_context` 是确定性的只读工具层，写计划继续通过 Action Registry 和用户确认；这比开放式 Function Calling 更容易审计，也更符合健康产品安全边界。
3. 不把模型输出的总数当真值。所有可计算总计由程序从明细重新计算。
4. 不宣称尚未测得的准确率。比赛报告只能引用冻结数据集实际运行生成的报告，并同时展示样本量、覆盖率、失败数和分层结果。

## 部署步骤

1. 后端发布前执行 Alembic 升级到 `0016_food_item_evidence`。
2. Worker 推荐配置：

   ```env
   VLM_PROVIDER=deepseek
   DEEPSEEK_VISION_MODEL=deepseek-flash
   DEEPSEEK_BASE_URL=https://api.deepseek.com
   DEEPSEEK_API_KEY=<secret>
   ```

3. 运行 `python doctor.py --vlm-smoke`，确认真实图片输入可用，再启动 Worker。
4. 用真实授权数据建立私有识餐标注集，运行 `scripts/evaluate_food_dataset.py`；报告和预测进入比赛证据包，原始含身份媒体不提交代码仓库。
