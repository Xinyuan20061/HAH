# 对外能力表与演示脚本（动作点评与语音闭环）

> 版本：2026-09-29；状态：**对外口径已定稿，工程已实现；独立集评测未跑，故不对外宣称任何准确率数字**。
> 严格遵守规格第 1 节"不承诺"边界：不写医疗级精度、不写高准确率、不把候选分值当真实准确率。
> 发布语统一使用"融合识别与可追踪点评"。

## 1. 对外能力表（可说 / 不可说）

| 能力 | 对外口径（可说） | 禁止表述 |
| --- | --- | --- |
| 动作识别 | 上传一段短视频，融合本地姿态与云端复核，给出识别类别与判断依据 | "准确率 XX%""医疗级""400 类全能识别" |
| 关键帧拆解 | 展示 3–4 个关键时刻的时间、观察与建议，每条标注证据来源 | "逐帧分析了完整动作周期" |
| 动作评分 | 仅对六种有专属评价器、且视频质量达标时给出次数与质量维度参考分 | "400 类都能打分""质量分=健康/风险结论" |
| 不确定处理 | 证据不足时明确提示"暂不能确定"，不硬给结论 | 把拒识包装成"已识别" |

| 语音闭环 | 语音转文字→健康 Agent→语音播报；长回复自动分段播报 | "永久已连接""已计费额度以我方为准" |

## 2. 演示脚本 A：一个真实视频的完整识别闭环

> 前置：准备一段用户授权的 5–20 秒六类动作视频（如前平举），已上传。（待实现确认：
> 演示素材需取得授权并做脱敏。）

1. 小程序进入"动作分析"页，只有**一个**"开始分析"按钮。
2. 点击上传视频，展示任务状态轮询：`queued → decoding → local_inference → evidence_ready →
   visual_review → feedback_generation → completed`。
3. 结果页顶部："识别到什么 / 是否可确认 / 整体点评"。
   - 展示识别类别（如"前平举"）与一句话依据。
   - 候选分值放在折叠详情，标注"模型候选分值，未经校准，不是准确率"。
4. 关键帧拆解：展示 3–4 个关键时刻，每项含时间戳、阶段、观察、一条可执行建议、所用证据。
5. 若该动作有评价器且质量达标：展示次数与质量维度分；若无评价器：明确显示
   "已识别类别，暂无可靠数值评分"，`score.available=false`。
6. 演示一个"不确定"分支：换一段低光/遮挡/非锻炼片段，展示系统提示"暂不能确定"，
   不硬给类别分。
7. 展示来源与限制：每条点评标注来源（本地/云端）、是否降级；底部"结果仅供一般健身参考"。

## 3. 演示脚本 B：一次语音闭环

1. 在对话页长按录音，说一句如"帮我看看今天的动作点评"。
2. 流程展示：录音上传 → 腾讯云 ASR 转文字（展示转写文本与 trace_id）→
   Health Agent Harness 路由并引用动作结果工具 → 生成回复文本 → 腾讯云 TTS 分段合成 →
   小程序顺序播放语音。
3. 长回复演示：让 Agent 回复一段较长文本，展示服务端自动分句、多段 mp3 顺序播放，
   而不是一整段截断。
4. 降级演示（可选）：弱网下展示超时后的可读降级提示；不静默失败。
5. 隐私口径：说明语音仅当次用于识别/合成，不留存。
