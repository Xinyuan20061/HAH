# HealthMate 功能汇总与能力分析报告

> 版本：2026-09-28（阶段 0/1/2 完成后）
> 依据：README.md、docs/VERIFICATION.md、docs/COMPETITIVE_DEVELOPMENT_PLAN_2026-09-27.md 及 benchmark-results/ 各评测报告。所有数字来自真实评测或已执行验证，未达标项如实标注。



***

## 1. 产品定位

**面向一般运动健康管理的可验证行动 Agent**：从用户自己的纵向记录发现一个具体变化，展示依据与数据质量，给出有停止条件的两档行动，由用户确认后执行；系统再用真实记录复盘，并明确结论的适用边界。

产品独特性落在 "观察 — 解释 — 确认 — 行动 — 复盘" 的**可审计机制**上，而非宣称发明新大模型、医疗诊断算法或高精度动作识别器。动作与识餐是辅助输入；可靠性不足时系统仍能完成记录、提醒、建议与复盘。



***

## 2. 系统架构



```
微信小程序（20 个页面，5 个 Tab）

&#x20;       │  wx.cloud.callContainer

&#x20;       ▼

微信云托管 FastAPI（backend/，Alembic 迁移 head=0022）

&#x20;       ├── DeepSeek 文本/识餐能力（按 AI\_MODE 切换）

&#x20;       ├── AIJob 队列（幂等/租约/超时重排/恢复）

&#x20;       ├── 持久 MySQL（生产） / SQLite（开发测试）

&#x20;       └── CloudBase 云文件引用（STORAGE\_BACKEND=cloud\_ref）

&#x20;       ▲

&#x20;       │  公网 HTTPS 轮询

本机 AI Worker（ai-worker/）

&#x20;       ├── OpenCV + MediaPipe 六类动作规则基线

&#x20;       ├── Kinetics-400 预训练推理（候选层，门控关闭）

&#x20;       ├── DeepSeek 识餐（云端直连失败时回落 Worker）

&#x20;       └── 能力探测（真实权重加载 + 单次前向 smoke）
```

关键设计：



* **任务可靠性**：同一媒体 / 任务幂等创建、租约续期、超时重排、临时 URL 刷新、页面恢复，`kinetics400` 与旧 `motion_pose`/`food_vision` 队列互不破坏。

* **模型不动生产**：Kinetics-400 与 Food-101 仅作实验候选层，`KINETICS400_OVERRIDE_ENABLED=false`，不自动覆盖规则或用户手选。

* **隐私边界**：生产容器不保存 SQLite、媒体原文件或视觉模型；用户媒体按 `healthmate/u<用户ID>/` 隔离；支持导出与删除。

### 3.3 Worker 端（本机 AI Worker）



| 能力               | 讲解                                                                                                           |
| ---------------- | ------------------------------------------------------------------------------------------------------------ |
| 六类动作规则基线         | OpenCV/MediaPipe 姿态解算 → 规则判定 6 类动作（arm\_abduction/arm\_vw/leg\_abduction/lunge/pushup/squat），三档 `AI_MODE` 路由 |
| Kinetics-400 候选层 | SlowFast-R50 预训练（132 MB）真实推理，400 类通用识别 → 中文映射 / 候选分值；**门控关闭**，仅记录候选与 `kinetics_note`，不覆盖规则                   |
| 识餐               | 云端 DeepSeek 直连，失败静默回队列回落 Worker；逐项食物证据、校正闭环                                                                  |
| 能力探测             | `kinetics400_status()` 真实权重加载 + 单次前向 smoke（模块级缓存），不把 "文件存在" 当 "能力就绪"                                         |
| 任务执行             | 幂等领取、长阻塞续租、临时文件 finally 清理、心跳                                                                                |

### 3.4 主创新：可验证行动账本（阶段 1）



* **决策读模型**：`GET /api/v1/agent/decisions/{decision_id}` 把一次微实验从 signal → evidence → proposal → confirmed action → progress → review 串成完整账本；decision\_id 服务端生成（`dec-<hex>`）、按用户隔离、他人 / 未知 id 一律 404（不可枚举）。

* **结论级证据标注**：`/agent/insights` 每条提醒带 `evidence_contract`——facts（只来自真实记录）、data\_coverage（observed/expected 均返回、缺失不按零）、knowledge\_ids（记录类为空并明示）、limitations、evidence\_type（record\_observation /general\_guidance）。

* **小程序行动时间线**：insights 页展示 "历史行动"（方案 / 状态 / 日期 / 复盘结论：支持 / 尚未支持 / 记录不足 / 已停止）与 "依据与数据覆盖 / 我们还不知道"，不暴露技术名词。

* **人在回路反馈**：用户对提醒给出 "有帮助 / 不准确" 反馈，纳入运行评测；反馈不自动训练模型或改写健康记录。

## 4. 能力分析（真实评测数据 + 能力分级）

### 4.1 动作识别



| 评测                                    | 口径                             | 结果                                                                                                              | 分级                                                       |
| ------------------------------------- | ------------------------------ | --------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------- |
| 六类规则基线（motion-v1）                     | REHAB24-6 全量 120 段             | 全样本准确率 41.67%、已接受准确率 64.94%、Macro-F1 54.15%、覆盖率 64.17%                                                          | **正式展示**（规则基线，如实标注边界）                                    |
| 同集三路对照（motion-v2-kinetics，2026-09-28） | 24 段子集（6 类 ×2 实例 × 双视角），同一输入视频 | 规则 Top-1 50.00% / 覆盖率 83.33% / Macro-F1 0.5765；Kinetics 单独 16.67% / 16.67%（仅 lunge 有映射）；融合 (模拟) 58.33% / 0.6127 | **全部未达 §7.2 门槛**（Top-1≥80%、覆盖率≥90%、Macro-F1≥0.78、召回≥65%） |
| Kinetics-400 候选层                      | 同集 24 段 + 3 段 smoke            | CPU 时延 P50≈100-106 s / 段；arm\_abduction 被识为 robot dancing 0.472 等；squat/pushup/lunge 有中文映射，其余仅英文 label          | **实验候选层**，`KINETICS400_OVERRIDE_ENABLED=false` 维持        |

**能力结论**：动作识别目前以规则基线为正式能力（演示用），Kinetics-400 增益未达标（覆盖率仅 16.67%，融合仅把 Top-1 从 50% 提到 58.33%），保持候选层；不启动训练、不删失败样本、不宣称高精度识别或专业评分。

### 4.2 识餐



| 口径     | 结果                                             |
| ------ | ---------------------------------------------- |
| 样本     | Nutrition5k 本地 RGB 子集 42 图，34 图有效（完成率 80.95%）  |
| 原始指标   | 热量 MAE 94.73 kcal、MAPE 72.70%                  |
| 区间协议   | 区间覆盖率 44.12%、宽度均值 140.26（中位 130 / P95 270）kcal |
| 中点校正代理 | MAE 94.01（改进仅 **0.76%**）                       |

**能力结论**：识餐为**实验入口**（逐项证据 + 可校正），未达 §7.3（区间覆盖≥80% 且用户可快速校正），不提升为正式推荐入口；单点热量不作为高精度卖点；食材代理标签不是标准菜名真值。

### 4.3 健康知识问答（RAG）



| 指标     | 结果（rag-v2，61 条冻结查询） |
| ------ | ------------------- |
| Hit@1  | 90.2%               |
| Hit@3  | 100%                |
| 无关查询拒绝 | 100%                |

**能力结论**：检索链路**正式可用**（来源引用、词法边界如 "好处 / 危害 vs 疾病指南" 如实标注）；但 "最终回答的事实正确率 / 引用支持率" 未经真实双人盲评，不得宣称 100%。

### 4.4 健康 Agent



| 指标          | 结果（agent-v2，33 条固定集，mock provider）   |
| ----------- | ------------------------------------ |
| 意图识别        | 100%                                 |
| 安全拦截        | 100%（含 3 类绕过变体：能停吗 / 晕倒 / 500 卡，已修复） |
| 结构契约 / 降级回退 | 100%                                 |

**能力结论**：Agent 路由与安全**正式可用**；真实 DeepSeek 在线回答质量**尚未通过双人盲评**（阶段 3 待做），微实验为个人自我观察、不推断因果。

### 4.5 主动提醒（确定性规则）

五类确定性扫描：运动断档、睡眠不足、动作表现下滑、体重连升、记录空白。证据契约保证：facts 只来自真实记录、数据不足时拒绝正向结论、无知识支撑降级为一般提示。**正式可用**（运行画像口径已核验）。

## 6. 安全与治理



* **模型门控**：`kinetics400_override_enabled=false`，候选层只记录不覆盖；能力探测 = 真实加载 + smoke，非 "文件存在"。

* **模型登记**：model\_governance 机制存在（ModelRegistry/ModelEvaluation/DatasetRegistry，含 release\_status/metrics/thresholds/gate\_status），评测以报告文件 + 哈希留痕，不写生产库。

* **安全拦截**：先确定性拦截红旗 / 危险建议再生成文本；安全规则不能被偏好学习绕过。

* **隐私**：媒体路径按用户隔离、权限仅创建者可读写；导出 / 删除回执留痕（服务端删除对账待阶段 3）。

* **失败样本**：一律保留不删除、不挑样本重算成绩；评测报告带清单与预测 SHA-256、门控参数、生成时间。

## 9. 限制与不能宣称



* 动作准确率仅对登记的 REHAB24-6 固定集有效；Kinetics 同集对照为子集口径、无独立验证集、softmax 未校准，不可用于设定上线阈值。

* 识餐 MAPE 72.70% 与区间覆盖 44.12% 未达建议门槛；食材代理标签不是标准菜名真值。

* Agent 双人盲评未做，不宣称 "真实在线回答质量通过盲评"。

* 微实验是个人自我观察，当前前后比较无随机对照，不推断因果。

* 正式微信环境、真机弱网、CloudBase 权限与删除对账未验收；本地验证≠生产验收。

* 不启动训练；外部模型权重按哈希登记但非六类微调产物，不得宣称为六类专属模型。
