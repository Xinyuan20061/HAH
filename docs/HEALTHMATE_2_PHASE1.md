# HealthMate 2.0 第一阶段落地说明

本阶段在现有“微信小程序 → 云托管 API → MySQL 队列 → 本地 AI Worker”链路上完成运动教练闭环，不改变既有媒体安全和异步调度边界。

## 已完成

1. 动作评分：Worker 根据动作深度、关键点可见度、躯干稳定性、动作周期和规则提示，输出完成度、稳定性、节奏控制、风险指数与综合分。所有分值均包含可解释依据和二维姿态估算声明。
2. 关键时刻：开始/伸展、最低点、完成、未完成和规则偏差最大时刻均带阶段、发现、依据和纠正建议。关键时刻同时返回匿名骨骼坐标，小程序直接绘制，不上传人物截图或背景。
3. 可信教学资源：`exercise_resources` 仅保存人工审核的真实链接。Agent 只负责识别动作语义，链接由数据库检索返回；模型回复中的网址会被过滤。
4. 持久化闭环：`motion_scores` 保存每次分析的四维评分和证据，`motion_events` 保存关键事件，为后续用户画像、成长曲线和动态计划提供事实数据。
5. 前端表达：视频分析页新增评分雷达图、四维分数、评分依据、匿名骨骼关键帧和逐帧纠正建议；聊天页新增可信教学资源卡片。

## 新增接口

- `GET /api/v1/exercise-resources?query=深蹲怎么做&limit=3`
- `GET /api/v1/fitness/training-adjustment`
  - 返回 `source=curated_database` 的已审核资源。
  - `url_policy=curated_database_only` 表明 URL 不来自模型生成。
- 原有 `POST /api/v1/worker/jobs/{job_id}/complete`
  - 动作任务可新增 `score` 字段。
  - 完成后自动写入动作评分与关键事件表。

## Motion Score 口径

- 完成度：动作最低角度相对当前动作参考阈值，并结合是否形成完整周期。
- 稳定性：关键点平均可见度与动作过程中躯干角波动。
- 节奏控制：至少两个完整周期时使用周期变异系数；证据不足时采用明确标注的保守基准分。
- 风险指数：按二维规则提示的严重程度累积，不表示医学风险概率。
- 综合分：完成度 38%、稳定性 28%、节奏控制 24%、安全度 10%。

## 能力边界

- 小程序默认使用自动识别；当前视频识别基线支持深蹲、俯卧撑和弓步蹲，证据不足或候选接近时拒绝猜测。动作效果知识图谱同时收录更多动作，用于训练部位和目标推荐，但不冒充视频识别能力。
- 当前识别器是可解释的二维骨骼特征匹配 v1，不是LSTM/ST-GCN训练模型；候选值是匹配分，不是统计概率。
- 分析为单机位二维启发式评估，机位、遮挡、衣着和视频质量会影响结果。
- 风险提示用于一般训练辅助，不构成医学诊断、康复处方或损伤概率。
- 教学资源会随内容下架而失效，上线运营时应定期人工复核 `active` 和质量评分。
