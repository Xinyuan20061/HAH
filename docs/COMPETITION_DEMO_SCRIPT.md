# 比赛演示脚本（3–5分钟）

1. **痛点与差异（20秒）**：健康工具通常等用户提问，而且建议依据不可见。用真实微信号进入首页，展示系统主动发现的一条记录变化。
2. **主动提醒闭环（35秒）**：打开“健康提醒”，说明系统只根据已记录数据保守判断；展示“观察到—建议先做—具体行动”，强调缺失数据不会被当作异常。
3. **可解释与可反馈 Agent（50秒）**：点击“问健康助手”，展示计划规划/运动指导/营养建议/安全守护的职责分工与“为什么这样建议”；对主动提醒标记“有帮助 / 不准确 / 已处理”，说明反馈只进入质量评测；生成计划后由用户确认才写入。
4. **动作闭环（50秒）**：先确认目标部位和训练目标，再上传10–20秒完整动作视频；展示CloudBase入云、Worker领取/进度、结果、动作效果语义和事件时间。当前六类规则基线固定集全样本准确率仅 41.67%，不可宣称高精度。
5. **识餐闭环（35秒）**：若真实视觉能力已通过 smoke，演示区间估算→校正→用户确认→记录；未启动时展示关闭状态和手动记录，不能用预制结果冒充识别。
6. **可信与降级（40秒）**：展示评测页的真实反馈样本与空样本口径，并展示双人评审工作簿；停 Worker 说明任务保留且普通业务正常，云模型失败时本地/规则接管。
7. **隐私与边界（20秒）**：展示导出和先删除 CloudBase 文件后清数据库；使用专用演示账号，不在现场误删重要账户。
