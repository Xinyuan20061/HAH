# HealthMate 动作点评与语音闭环：隐私文案与数据流说明

> 版本：2026-09-29；状态：**工程实现已落地并本地复验（脱敏像素检查/账本字段已核对），正式上线前仍需与现行隐私政策合并审阅**。
> 核心原则：原视频/原语音不落库；默认不把真实人物画面发给云端模型。

## 1. 一句话数据流

用户上传一段 5–20 秒视频（或录一段语音）→ 云端只做任务调度与结构化结果存储 →
本地 Worker 解码视频、抽帧、跑姿态与动作候选 → 发送给云端大模型的只是**脱敏关键帧或纯色画布骨架图**
（需用户同意）→ 模型返回类别复核与点评文本 → 服务端校验后落结构化结果 → 原视频/原语音不留存。

## 2. 哪些数据存、哪些不存

| 数据 | 是否落库 | 说明 |
| --- | --- | --- |
| 原始视频文件 | **不落库**（存 CloudBase 用户私有对象存储，短期签名访问） | 删素材/账号时按隐私流程删除 |
| 原始语音音频 | **不落库**、不留存 | 只用于当次 ASR 调用；`provider_invocations` 只存计数与指纹 |
| 发送给 DeepSeek 的图像 | 默认**纯色画布骨架图**（无原人物像素） | 用户另行同意真实帧时才发送，且先做像素级脱敏 |
| 结构化分析结果 | 落 `motion_analysis_feedback.result_json` | 类别、证据引用、点评文本、来源/降级标记 |
| 调用账本 | 落 `provider_invocations` | 只存 provider、operation、请求指纹、状态、时延、token/字符数、腾讯云 RequestId、成本估算；**不存原始音频、图片、完整 prompt、密钥** |
| 语音用量 | 落 `voice_usage_daily` | 按用户/日/provider 的次数与字符数；本地预算，不冒充腾讯云控制台余量 |

## 3. 关键帧脱敏策略

- **默认方案：纯色画布骨架图。** 在纯色背景上绘制骨架关键点与必要数值，不包含原人物轮廓、
  服装、背景环境。上线前须做像素级抽审，确认不存在可识别人物/场地。
- **用户同意真实帧：** 仅在用户主动开启"云端视觉协作"时发送真实关键帧，且先对人脸与
  可识别区域做像素级模糊；抽审脱敏后仍不可识别身份。
- 用户可随时关闭云端视觉协作；关闭后结果页标"仅本地分析"，已缓存的该用户视觉复核与点评按用户清理。
- 关键帧预览使用短期签名地址，**7 天保留**；过期后仅保留结构化证据（时间戳、阶段、文字）。

## 4. 同意、撤回、删除与导出

- 每次使用云端视觉协作前需用户同意（`consent_deepseek_frames` + `consent_version`）。
- 撤回同意：立即关闭云端视觉协作，并清理该用户相关缓存。
- 删除素材/账号：级联清理结构化反馈、短期关键帧、调用明细中可关联该用户的行；
  审计所需最短保留期除外。
- 导出：用户可导出自己的分析记录与调用摘要（脱敏）。
- 越权：A 用户不能读取/触发 B 用户的任何分析或语音配置（接口返回 404，不暴露存在性）。

## 5. 对外可使用的表述边界

- 可以说："融合本地姿态识别与云端复核，给出可追踪证据链的动作点评。"
- 不可以说："医疗级精度""诊断/康复建议""高准确率""候选分值等于真实准确率"。
- 语音：说明语音会被发送到腾讯云做一次识别/合成，仅当次使用、不留存；说明免费额度与
  预算机制以控制台为准。
