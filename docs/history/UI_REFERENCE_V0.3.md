# V0.3 UI 参考与设计取舍

本次没有直接照搬某个产品，而是提炼健康 / 健身类产品中更成熟的移动端信息层级：

- Didiye：把“本周连续记录 + 扫描餐食”放到首页首屏，说明 AI 拍照入口应该比普通记录更醒目。
- FitIntel：周报使用少量关键数字 + 趋势图，而不是展示大量原始数据。
- NutriMate：拍照识餐页将照片本身作为核心视觉，营养结果以底部信息层呈现。
- Pally：产品围绕“一天”组织，而不是围绕功能清单组织；首页突出 next best action。
- 2026 AI App UI 趋势：流式文本、柔和玻璃感、Skeleton / 反馈状态、AI 原生交互，而不是单独放一个聊天页就算 AI 产品。

因此 HealthMate V0.3 的核心设计原则是：

1. 首页首先回答“我今天怎么样、下一步做什么”。
2. 拍照识餐 / AI 健身 / 周报 / 视频入口属于一级能力，用 Bento Grid 直接可见。
3. 图表只表达趋势，不做复杂 BI。
4. AI 对话必须有实时生成状态和数据上下文感。
5. 健康类产品不能用夸张的“诊断式”文案，应明确估算与生活建议边界。
6. 视觉上避免纯白卡片堆叠，采用深绿核心品牌色 + 酸橙强调色 + 低饱和辅助色。
