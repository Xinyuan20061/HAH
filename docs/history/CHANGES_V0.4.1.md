# v0.4.1 API Connectivity Hotfix

本次版本不继续堆功能，优先修复“API Key 无法保存 / 保存后无法使用”的前后端联调问题。

## 根因

1. 小程序默认后端地址写死为 `http://127.0.0.1:8000/api/v1`。如果 FastAPI 没启动，请求不会到达后端；真机调试时 `127.0.0.1` 指向手机自身，更不可能访问电脑上的后端。
2. App 启动登录是异步的，而 AI 设置页之前没有主动等待登录完成，首次进入时可能出现 401。
3. 请求层没有 401 自动重新登录，也没有把网络错误、HTTP 状态和后端地址清楚显示出来。
4. 新用户录入 API Key 时，如果忘了开启“启用用户自定义模型”，Key 虽然能保存，但 AI Gateway 不会使用它，体验上会像“保存无效”。

## 修复

- 请求层改为动态读取后端地址，并支持开发环境本地切换。
- AI 设置页增加“后端连接状态 / 检测后端连接”。
- 真机调试可以直接在页面填写电脑局域网 API 地址。
- API 设置页在读写配置前主动确保登录。
- 请求遇到 401 时自动重新登录并重试一次。
- 网络错误会直接提示当前后端地址以及“FastAPI 未启动 / 真机不能使用 127.0.0.1”等关键信息。
- 第一次保存新 API Key 时，如果用户没有主动打开开关，会自动启用用户自定义模型，避免“保存了但没生效”。
- 我的页面读取用户与 AI 配置前也会确保登录。

## 推荐测试顺序

1. 启动 FastAPI：`uvicorn app.main:app --reload --port 8000`。
2. 浏览器访问 `http://127.0.0.1:8000/health`，必须看到 `status: ok`。
3. 微信开发者工具进入“我的 → DeepSeek 模型设置”，点击“检测后端连接”。
4. 输入 DeepSeek API Key，先点“测试 DeepSeek 连接”，成功后再“保存配置”。
5. 返回 AI 助手，发送一条消息，顶部 Provider 应显示“我的 DeepSeek”。
6. 真机调试时，把后端地址改为 `http://<电脑局域网IP>:8000/api/v1`；正式上线改成 HTTPS 域名。
