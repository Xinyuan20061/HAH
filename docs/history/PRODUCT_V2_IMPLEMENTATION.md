# HealthMate v0.2 前端产品化说明

## 信息架构

### 首页
从“3 个数字”扩展为今日健康仪表盘：饮水、睡眠、运动、蛋白质、今日计划完成度、AI 建议、四个快捷入口。

### 记录
形成三层结构：
- 日常状态：健康打卡；
- 行为数据：饮食、运动；
- 反馈层：7 日趋势。

### 计划
计划任务来自后端并可勾选完成，状态按“用户 + 日期 + task_key”持久化，不再是只读占位卡片。

### AI 助手
聊天结果会显示实际 Provider 类型。用户可以直接跳转模型设置。聊天上下文继续复用健康档案与今日数据。

### 我的
加入健康档案、DeepSeek 模型设置、7 日趋势、安全说明，使“我的”成为真正的账户与个性化中心。

## 视觉原则

- 主色采用低饱和深绿，表达健康、可信与长期使用感。
- 卡片圆角、阴影和间距统一，避免比赛作品常见的“每页一种样式”。
- 首页使用深色渐变作为视觉锚点，其余页面保持白底和浅灰绿背景，控制信息密度。
- 快捷入口使用弱色块区分类别，不依赖大量图片资源，减少微信小程序包体积。

## 下一阶段预留

- 食物拍照识别：后端已有 `vision` service/interface，可接入视觉模型 + 食物营养数据库。
- 微信运动/健康数据授权：可将手动步数替换或合并为授权数据。
- AI 流式输出：当前接口为非流式，后续可用 SSE/WebSocket 或微信支持的分块请求改造。
- 更专业趋势图：当前无需第三方图表库即可运行，后续可接 ECharts 小程序版。
